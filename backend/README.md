# Apps Script 배포 가이드

`Code.gs`는 현재 운영 중인 Google Sheet에 연결하는 백엔드 원본입니다. GitHub Pages만 배포해서는 학기 기능이 활성화되지 않습니다.

1. 운영 스프레드시트에서 `확장 프로그램 → Apps Script`를 엽니다.
2. 기존 코드를 별도 파일/버전으로 백업한 뒤 `backend/Code.gs` 내용으로 교체합니다.
3. Apps Script 편집기에서 `migrateTerms()`를 한 번 실행하고 권한을 승인합니다.
4. 실행 로그가 `기존 데이터가 2026-2 학기로 안전하게 인식되었습니다.`인지 확인합니다.
5. 스프레드시트에 `학기`, `학기설정` 탭이 생기고 기존 데이터 탭 끝에 `TERM_ID` 열이 추가됐는지 확인합니다.
6. `배포 → 배포 관리 → 수정 → 새 버전 → 배포`로 기존 웹 앱 URL을 유지한 채 재배포합니다.
7. 웹에서 관리자 로그인 후 `학기 관리`를 열어 `2026-2학기 · 현재 운영` 표시를 확인합니다.

마이그레이션은 기존 행을 삭제하거나 이동하지 않습니다. 빈 `TERM_ID` 셀에만 `2026-2`를 채우며 여러 번 실행해도 중복 학기나 중복 데이터가 생기지 않습니다. `seedSampleData()` 같은 샘플 입력 함수는 포함하지 않았습니다.
