# 근로장학생 근무관리

GitHub Pages 프런트엔드와 Google Apps Script/Google Sheet 백엔드로 구성된 운영 시스템입니다.

## 학기 데이터 구조

- `학기`: `TERM_ID`, 표시명, 시작/종료일, 활성 상태를 관리합니다.
- `학기설정`: 학기별 운영기간, 시급, 화면 문구와 링크를 보관합니다.
- 기존 데이터 탭: 기존 열과 값을 유지하고 마지막에 `TERM_ID`만 추가합니다.
- `설정`: 관리자 PIN과 `ACTIVE_TERM_ID`를 유지합니다. 관리자 계정은 학기 전환과 무관합니다.

새 학기는 학생 기본정보/PIN, 고정근무표, 운영설정, 휴일을 선택적으로 복사할 수 있습니다. 예산은 0으로 시작하고 결근, 대타, 추가근무, 공지, 이벤트 등 운영 기록은 복사하지 않습니다. 과거 학기는 관리자 조회만 허용하며 백엔드에서도 쓰기를 거부합니다.

관리자는 `결근·대타` 화면의 `관리자 결근 등록` 버튼으로 학생을 대신해 결근을 등록할 수 있습니다. 학생의 실제 고정근무와 겹치는 시간만 허용되며 등록 즉시 대타 모집 상태가 됩니다.

학생 홈과 관리자 대시보드의 `근무 공유 메모`는 현재 학기의 인수인계 내용을 함께 보여줍니다. 학생은 본인 메모만 삭제할 수 있고 관리자는 모든 메모를 삭제할 수 있으며, 서버가 작성자 고유키와 권한을 검증합니다. 메모는 `근무공유메모` 탭에 소프트 삭제 방식으로 보관되고 한 건당 500자로 제한됩니다.

운영 적용 절차는 [backend/README.md](backend/README.md)를 참고하세요.

## 학생별 월간 시간·금액

관리자 `예산·시간`에서 월을 선택하면 학생별 근무표 시간과 기본 금액을 조회할 수 있습니다. 점심 제외·결근·확정 대타·추가근무 신청은 기존 예산 원장과 같은 기준이며 해당 월 전체 예정 근무를 포함합니다. 연도별 학기 설정 시급을 사용하고 지급 확정 기능은 포함하지 않습니다.

현재 학기 관리자는 학생의 월 총시간을 보정하거나 근무표 기준으로 복원할 수 있습니다. 보정은 기존 시간을 대체하며 원본 근무표·기존 예산 예측을 바꾸지 않습니다. 사유·수정자 표시·시각·수정 전후 시간은 별도 이력에 남습니다. 공용 관리자 PIN은 개인을 식별하지 않으므로 수정자 표시는 직접 기입한 정보로 표시합니다. 과거 학기는 조회만 허용합니다.

`monthly-hours.js`와 `backend/MonthlyHours.gs`는 동일한 계산 모델입니다. 변경 시 두 파일을 함께 갱신하고 테스트로 바이트 일치를 확인합니다. 백엔드 미설정 시 월간 기본 조회는 가능하며 보정 버튼은 나타나지 않습니다. 적용 절차는 backend/README.md의 월간 시간 보정 절을 참조하세요.
